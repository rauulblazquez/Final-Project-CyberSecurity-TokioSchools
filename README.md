- **Tools:** Nmap, Nikto, Gobuster, WhatWeb, Curl, Shodan.
- **Key Findings:** Identified 4 configuration issues (missing HTTP security headers, cookies without `HttpOnly`).
- **Outcome:** Full analysis, remediation plan, and security policies attached in the PDF report.
